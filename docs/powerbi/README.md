# Power BI dashboard screenshot

The main [README](../../README.md#-power-bi-dashboard) embeds `dashboard.png` from this folder.

To add it:

1. Open `powerbi-project/FxDashboard.pbip` in Power BI Desktop and go to the page you want to feature (the **Compliance** page makes the strongest thumbnail).
2. Capture it — either **File → Export → Export to PDF** and screenshot a page, or just use the Windows Snipping Tool (`Win`+`Shift`+`S`) on the report canvas.
3. Save the image as `docs/powerbi/dashboard.png` (overwriting nothing — this folder currently has only this note).
4. Commit it; the README image will then render.

Optionally add per-page images (`allocation.png`, `rates.png`, `compliance.png`) and reference them in the README.
